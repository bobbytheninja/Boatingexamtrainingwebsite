🚀 DEPLOY TO VERCEL - NO SUDO NEEDED
================================================

ERROR: EACCES permission denied when installing vercel globally
SOLUTION: Use npx instead (no installation needed!)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ RECOMMENDED METHOD - USE NPX:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

npx vercel login
npx vercel --prod

That's it! npx downloads and runs vercel temporarily.
No global installation needed!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FULL DEPLOYMENT STEPS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ Clean and install dependencies:

rm -rf node_modules dist .vite package-lock.json
npm install


2️⃣ Build the project:

npm run build

✅ Should see: "✓ built in Xms" and create 'dist' folder


3️⃣ Login to Vercel:

npx vercel login

Follow the prompts to authenticate


4️⃣ Deploy to production:

npx vercel --prod

Vercel will:
- Upload your files
- Run npm install
- Run npm run build
- Deploy your app
- Give you a live URL


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AFTER DEPLOYMENT:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Add environment variables in Vercel Dashboard:
   - Go to vercel.com → Your Project → Settings → Environment Variables
   
   Add these:
   VITE_SUPABASE_URL=your_url_here
   VITE_SUPABASE_ANON_KEY=your_key_here
   VITE_STRIPE_PUBLIC_KEY=your_key_here

2. Redeploy:
   - Deployments tab → Click "Redeploy" on latest deployment

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ALTERNATIVE: Fix Permissions (if you really want global install)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A - Quick (uses sudo):
sudo npm install -g vercel

Option B - Better (changes npm config):
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc
npm install -g vercel

But honestly, just use npx! It's easier and recommended.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

COPY-PASTE THIS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

rm -rf node_modules dist .vite package-lock.json && npm install && npm run build && npx vercel --prod

This does everything in one command chain!
