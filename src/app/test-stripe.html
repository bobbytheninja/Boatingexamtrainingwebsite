💳 Stripe Configuration Test

Diagnose and fix your "Failed to start checkout" error

🚨 Your Current Issue

Error: "Failed to start checkout"

Cause: Stripe API key (STRIPE_SECRET_KEY) is not configured in Supabase

Solution: Follow the steps below to add your Stripe key

Step 1: Get Your Stripe Secret Key

You need to get your API key from Stripe first.

1 Go to Stripe Dashboard (Test Mode):

👉 Click Here: https://dashboard.stripe.com/test/apikeys
2 Find "Secret key" section
(NOT "Publishable key" - that's different!)
3 Click "Reveal test key"
The key starts with: sk_test_...
4 Copy the entire key
You'll use it in Step 2 below

Step 2: Add Key to Supabase

Run this command in your terminal (replace with your actual key):

npx supabase secrets set STRIPE_SECRET_KEY=sk_test_YOUR_KEY_HERE

Example:

npx supabase secrets set STRIPE_SECRET_KEY=sk_test_51AbC...

✅ Wait for: "Finished supabase secrets set"

Step 3: Redeploy Backend

Backend needs to restart to load the new secret:

npx supabase functions deploy server --no-verify-jwt

✅ Wait for: "Deployed Function server"

Step 4: Test Checkout Endpoint

After completing Steps 1-3, test if Stripe is configured:

✅ Verify Configuration

After steps 1-3, verify your secrets are set:

npx supabase secrets list

Should show:

NAME VALUE STRIPE_SECRET_KEY sk_test_...

If STRIPE_SECRET_KEY is missing: Go back to Step 2

🎯 Success!

You'll know it's working when:

  • ✅ "Test Checkout Endpoint" button above returns success
  • ✅ Clicking "Purchase" in your app redirects to Stripe checkout page
  • ✅ No more "Failed to start checkout" error
