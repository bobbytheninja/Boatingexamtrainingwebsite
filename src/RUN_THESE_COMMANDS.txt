STEP 1: Deploy Backend (I fixed the config!)
---------------------------------------------
npx supabase functions deploy server --no-verify-jwt


STEP 2: Get Stripe Key
---------------------------------------------
Open in browser: https://dashboard.stripe.com/test/apikeys
Click "Reveal test key"
Copy the key (starts with sk_test_)


STEP 3: Set Stripe Key (REPLACE with your actual key!)
---------------------------------------------
npx supabase secrets set STRIPE_SECRET_KEY=sk_test_YOUR_ACTUAL_KEY_HERE


STEP 4: Redeploy Backend (to load the Stripe key)
---------------------------------------------
npx supabase functions deploy server --no-verify-jwt


STEP 5: Check Logs (verify Stripe initialized)
---------------------------------------------
npx supabase functions logs server

Look for: "✅ Stripe initialized successfully"


STEP 6: Refresh Your App & Try Checkout
---------------------------------------------
- Refresh browser (Ctrl+Shift+R or Cmd+Shift+R)
- Click "Purchase" button
- Should redirect to Stripe immediately!
