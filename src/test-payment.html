🔍 Troubleshooting

Error: "Payment system unavailable - Stripe not configured"

  • STRIPE_SECRET_KEY is not set in Supabase
  • Run: npx supabase secrets set STRIPE_SECRET_KEY=sk_test_...
  • Redeploy backend after setting the secret

Error: "Missing authorization header"

  • Make sure you're logged in
  • The access token might have expired - try logging out and back in

Checkout session doesn't redirect

  • Check browser console for errors
  • Verify the response from /create-checkout-session includes a URL
  • Check Supabase Functions logs for backend errors
