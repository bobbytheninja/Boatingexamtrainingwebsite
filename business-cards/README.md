## Printing Options Explained

### ✅ RECOMMENDED: UV Lamination (UV лак)
- **What it is:** Clear glossy coating cured with UV light
- **Benefits:** Waterproof, scratch-resistant, makes colors pop
- **Cost:** Low additional cost
- **Why for you:** Perfect for marine/boat business - protects from water splashes

### 🌟 OPTIONAL: Warm Stamp (Топъл печат)
- **What it is:** Metallic foil (gold, silver, copper) pressed into card
- **Benefits:** Premium luxury look, tactile feel
- **Cost:** Higher additional cost
- **Recommendation:** Gold foil on yacht icon would look amazing!

### 🎨 ALTERNATIVE: Soft Touch
- **What it is:** Matte velvet-like finish
- **Benefits:** Elegant, fingerprint-resistant, unique feel
- **Cost:** Moderate
- **Recommendation:** Good alternative to glossy if you want subtle/classy

### 🔺 PREMIUM: Embossing (Релеф)
- **What it is:** Raised 3D effect on logo/text
- **Benefits:** Very premium, tactile
- **Cost:** Highest
- **Recommendation:** Would make yacht icon really stand out

## Before Uploading to Printer

### 1. Generate Real QR Code
The designs have "QR CODE" placeholders. Generate actual QR codes:

**For business cards:**
- QR Code should link to: `https://blackseabulgaria.com`
- Use this free generator: https://www.qr-code-generator.com/
- Size: 600×600px minimum
- Format: PNG or SVG
- Error correction: High (30%)

**How to insert:**
1. Open the SVG file in Illustrator, Inkscape, or Figma
2. Delete the placeholder rectangle with "QR CODE" text
3. Import your generated QR code
4. Position it in the same spot
5. Export as PDF for printer

### 2. Add Your Contact Info
Replace placeholders in the back designs:
- **Phone:** Replace `+359 XXX XXX XXX` with your actual phone
- **Email:** Replace `info@blackseabulgaria.com` with actual email
- **Address:** Add specific city/location if you want

### 3. File Format for Printer
weprint.bg accepts:
- PDF (BEST - preserves quality)
- AI (Adobe Illustrator)
- PSD (Photoshop)

**How to convert SVG → PDF:**
- **Option 1:** Open in Adobe Illustrator → File → Save As → PDF
- **Option 2:** Open in Inkscape (free) → File → Save As → PDF
- **Option 3:** Use an online converter (be careful with bleed settings)

### 4. Check Bleed & Safe Area
All designs include 2mm bleed:
- **Bleed:** Extra 2mm around edges (printer will trim this)
- **Safe area:** Keep important text/images 2mm from trim edge
- **Current designs:** Already include proper bleed
