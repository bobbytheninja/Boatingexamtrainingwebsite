# How to Insert Your QR Code into the Designs

Your QR code is located at: `/src/imports/image.png`

## Method 1: Using Adobe Illustrator (Recommended)

1. **Open the SVG file** in Adobe Illustrator
   - File → Open → Select `qr-sticker-anchor-filled-100mm.svg`

2. **Delete the placeholder**
   - Find the text that says "QR CODE IMAGE"
   - Delete the placeholder rectangle/text

3. **Place your QR code**
   - File → Place
   - Navigate to `/src/imports/image.png`
   - Click to place it in the center
   - Resize to approximately 200×200px

4. **Position it correctly**
   - Center it within the anchor design
   - Make sure it's readable and not covered by anchor elements

5. **Export as PDF**
   - File → Save As → PDF
   - Use "High Quality Print" preset
   - Upload this PDF to weprint.bg

## Method 2: Using Inkscape (Free)

1. **Open the SVG file** in Inkscape
   - File → Open → Select the anchor sticker SVG

2. **Import your QR code**
   - File → Import
   - Select `/src/imports/image.png`
   - Choose "Embed" (not link)

3. **Resize and position**
   - Drag the QR code to the center
   - Resize to fill the anchor shape

4. **Export as PDF**
   - File → Save As → PDF
   - Upload to weprint.bg

## Method 3: Quick Online Tool

1. **Use an online SVG editor**
   - Go to: https://www.photopea.com/ (free Photoshop online)
   - File → Open → Upload the SVG

2. **Add your QR code**
   - File → Open & Place → Upload `image.png`
   - Resize and position

3. **Export**
   - File → Export as → PDF
   - Download and upload to printer

## For Business Cards

The business card back designs also need the QR code inserted:
- `mini-card-75x43mm-back.svg`
- `standard-card-85x55mm-back.svg`

Same process:
1. Open in Illustrator/Inkscape
2. Delete the "QR CODE" placeholder
3. Place your `image.png`
4. Resize to fit the allocated space
5. Export as PDF

## Quick Check Before Printing

✅ **Test the QR code works:**
- Scan it with your phone before sending to printer
- Make sure it goes to: blackseabulgaria.com

✅ **Check size:**
- QR code should be at least 2cm × 2cm to scan reliably
- Don't make it too small!

✅ **Verify positioning:**
- QR code shouldn't be too close to edges
- Leave some white space around it

## Need Help?

If you have trouble, you can also send the SVG files + your QR code image to a local print shop and they'll insert it for you (usually for free as part of print prep).
